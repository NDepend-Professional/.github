## First Look at NDepend Professional

NDepend Professional is for people who keep .NET assemblies they own and want one named .NET desk, not unmarked builds. It gives you code metrics, own assemblies, and a short path back to a project you already run. It does not replace Visual Studio. It sits beside Visual Studio and keeps the graphs close.
